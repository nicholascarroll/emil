# GCC for the AIX CI job, from IBM's AIX Toolbox for Open Source Software:
#   https://public.dhe.ibm.com/aix/freeSoftware/aixtoolbox/RPMS/<path>
#
# The AIX image ships no C compiler, only the bos.adt headers, libraries,
# as and ld.  This is the smallest set that gives a working gcc: the
# compiler itself, the libraries cc1 links against, and the unversioned
# gcc/cpp/libgcc wrappers that put plain `gcc` on PATH.
#
# guest.sh installs these with --nodeps.  The full dependency closure
# is about 28 packages, and what the rest adds is bash, info and GNU sed
# for the post-install scripts, plus libstdc++ (64 MB), which gmp
# declares only for its C++ binding.  None of it is on the path from a
# .c file to an executable.  Of the post-install work, only the info
# pages are lost (install-info is absent and its failure is ignored);
# GCC's fixed headers are regenerated with the system sed standing in
# for GNU sed, see guest.sh.
#
# Each line: sha256, then the path under RPMS/.  The hashes come from
# the Toolbox repodata (primary.xml.gz); fetch.sh refuses a mismatch,
# and guest.sh checks IBM's signature on each one as well.
